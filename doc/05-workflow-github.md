# Editing via GitHub Web Interface

If you do not have coding tools installed, you can make updates directly from your browser using GitHub.

1. **Navigate to the Repository**: Open the GitHub page for `abandet-makutu-site`.
2. **Find the File**: Navigate through the folder structure (e.g., `content/news/`) to find the file you want to edit.
   * *To add a new file*: Click the "Add file" button in the top right of the file list and select "Create new file".
3. **Edit the Content**: 
   * If editing, click the pencil icon ✏️ to open the text editor.
   * Make your Markdown and frontmatter changes.
4. **Commit the Changes**:
   * Scroll to the bottom of the page to "Commit changes...".
   * Enter a brief descriptive message (e.g., "Add new team member: Jane Doe").
   * Select "Commit directly to the `main` branch" (or create a new branch if your team uses pull requests).
   * Click the "Commit changes" button.
5. **Add Images**: To upload images for new members, navigate to their folder, click "Add file" -> "Upload files", drag your `avatar.jpg` in, and commit.
